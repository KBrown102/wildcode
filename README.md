# 野码 WILD CODE — 个人作品集

荒野的个人作品集站点：独立开发者 / 游戏创作者 / Builder。

- 原生 HTML + CSS + JavaScript，无构建依赖，静态托管即可运行
- Three.js 浮岛背景 + 五只性格各异的小马 + 各作品专属联动特效
- 收录 10+ 原创开源作品：游戏、创意工具、壁纸系列
- 在线试玩 / GitHub 源码入口 / 成长线时间轴

## 本地打开

直接双击 `index.html` 即可（本地环境下旅行牛仔实时预览层自动停用，线上部署后正常）。

## 部署（GitHub Pages + 自定义域名）

1. 新建 public 仓库 `wildcode-site`，上传本目录全部内容（含 `.gitignore`、`CNAME`、`README.md`、`assets/`、`mp3/`）
2. 仓库 Settings → Pages → Source 选 `main` 分支根目录
3. Custom domain 填 `wildcode.club`，Enforce HTTPS 勾选
4. 在域名注册商 DNS 加一条 CNAME：`wildcode.club` → `kbrown102.github.io`

> `.cn` 域名（wildcode.cn）留待日后备案后接入，当前站点走 `.club`。
